## これは何か

主人公は月そのものです。中盤からカメラは月面に固定され、地球を見つめ続けます。

土台にしている事実はすべて本当のことです。

- 月は45億年前、地球への天体衝突で飛び散った破片から生まれた
- 月は潮汐ロックにより、常に同じ面を地球に向けている
- 月は年に約3.8cmずつ地球から遠ざかっている
- 月には風がないため、人類の足跡は1億年以上消えない

画面に出る文字は、最後の一行とタイトルだけです。

> 月は今も、年に3.8cmずつ遠ざかりながら、同じ顔を地球に向けている

| 時間 | シーン | 起きること |
|:--|:--|:--|
| 0:00–0:50 | **誕生** | 火星ほどの天体が溶けた地球をかすめる。破片は円盤になって渦を巻き、地球のすぐそばで赤く大きな月に集まる |
| 0:50–1:40 | **向き合う** | 月が冷えて灰色に。カメラは月面に降り、自転が減速して止まると、空を横切っていた地球も止まる。地球は冷えて青くなり、少しずつ小さくなる |

## 観る

- **オンライン**：[futurecortexlabs.github.io/FCTX-Waiting-Moon](https://futurecortexlabs.github.io/FCTX-Waiting-Moon/)。公開版には NASA のテクスチャと音楽が入っていないので（[素材](#素材任意)を参照）、地球は手続き生成で描かれ、音は鳴りません。
- **手元で**：Node.js 24 が必要です（[`.nvmrc`](.nvmrc)）。

  ```bash
  npm install
  npm run dev      # http://localhost:5173 が開きます
  ```

開くと自動で始まり、最後まで再生されます。ブラウザは操作のあとでないと音を出せないので、一度クリックするかキーを押してください。その時点の位置から音楽が重なります。

| キー | |
|:--|:--|
| `Space` | 一時停止／再開 |

### デバッグ用クエリ

| クエリ | 意味 |
|:--|:--|
| `?scene=footprint&t=30` | シーン「足跡」の30秒目から再生 |
| `?t=123` | 作品全体の123秒目から再生 |
| `?debug` | タイムスライダー（lil-gui）、シーンへのジャンプ、fps |
| `?q=low` | 軽量モード（粒子数・解像度を下げ、MSAA を切る） |
| `?mute` | 音楽を読み込まない |
| `?paused` | 止めた状態で開く |

シーン名：`birth`（0:00）、`lock`（0:50）、`watch`（1:40）、`spark`（2:30）、`footprint`（3:30）、`remain`（4:20）

## 仕組み

Vite + TypeScript + Three.js r180。作品全体を GSAP のタイムライン1本にまとめています。

```
毎フレーム
  |
  +- 時計          音楽が鳴っていればその再生位置、鳴っていなければ経過時間
  +- タイムライン  gsap master.time(t) -> era, moonDist, moonHeat, tide, fade, line, title, bloom
  +- ディレクター  ラベルからシーンを決める -> 前のシーンを dispose / 次を setup -> scene.update(ローカル時刻)
  +- ステージ      宇宙（地球半径 = 1）か月面（1 = 1m）。対数深度バッファ
  +- 描画          EffectComposer：RenderPass -> UnrealBloomPass -> OutputPass（ACES）
```

どのシーンも時刻だけで決まるので、`?scene=` やデバッグ用スライダーでどこへ飛んでも、通しで再生したときと同じ画になります。

### 地球はひとつ、uniform もひとつ

`Earth` はひとつのクラスで、シェーダーが `uniform float era`（0〜1）ひとつからすべての時代をブレンドします。光る割れ目のある溶岩、冷えた岩、蒸気の雲に覆われた海の惑星、むき出しの大陸、緑、赤道近くまで凍る氷期、また緑、現代の地球（Blue Marble）、最初の火、そして明るい都市から順に灯って広がる都市の光（Black Marble）。大陸はノイズの座標をずらして動かしています。縁の光は、フレネルの縁取りと別の大気の殻で出しています。

### 月から見る潮汐

海面の殻を、頂点シェーダーで月の方向へ数%膨らませています（P2 の形なので反対側も膨らみます）。ただ月から見ると膨らみはまっすぐカメラの方を向くので、フラグメントシェーダーでも膨らみの下の海面を上げています。大陸が膨らみの下を通るとき、海岸線が水に沈みます。

### 潮汐ロック

カメラは月面のアンカーに乗っています。地球直下点から75°離れた所なので、地平線が画面に入ります。月がまだ自転している間は地球が空を横切り、残りの自転がイージングでゼロになると、1:32 に地球が地平線の上で止まります。

### 足跡

足跡のまわりの地面は `PlaneGeometry` と 1024² の浮動小数点ハイトマップ（`DataTexture`）で、ハイトマップを変位マップとして使っています。靴底の形は符号付き距離関数で、ブーツのメッシュと足跡の両方が同じ形を使います。足跡には傾いた壁、シェブロン模様の溝、押し出された砂の盛り上がりがあります。フラグメントシェーダーでハイトマップから法線を計算しなおすので、低い太陽が足跡の中に影を落とします。足跡の形は一度だけ計算し、毎フレームはブーツの沈み具合を掛けるだけです。

### 低重力の砂煙

砂の粒はどれも頂点シェーダーの中で `p = p0 + v·t − ½·1.62·t²` に従って動き、地面に着いたところで止まります。空気がないので漂わず、弧を描いてゆっくり落ちます。

### 人間

登場するのはブーツと手袋だけです。顔や全身は描きません。

Chromium（Claude デスクトップアプリ内蔵ブラウザ）、NVIDIA RTX PRO 6000 で確認しました。

- `npm run typecheck` と `npm run build` が通ること。

## 既知の限界

- **月面ステージへの最初の切り替えで一度だけ止まる。** 2:30 の時点で、上の GPU で約 0.2秒。画面が真っ黒な間です。音楽が鳴っていれば、そのあと映像が音楽に追いつきます。
- **向き合う・見守るで見える月の地面は、近くで見ると柔らかい。** クレーターは球に手続き生成で凹凸の陰影をつけたもので、形状ではありません。
- **テクスチャが無いと、現代の地球も手続き生成になる。** `earth_day.jpg` を置くまで、実際の大陸の形にはなりません。
- **音を出すには一度クリックかキー入力が要る。** ブラウザの自動再生の決まりです。
- **公開版は無音で、NASA のテクスチャも無い。** どちらもリポジトリに入っていないためです。
- **このリポジトリの確認では、実時間で通しては観ていない。** 通しの確認はフレームを刻んで進めたものです（[検証](#検証)を参照）。
