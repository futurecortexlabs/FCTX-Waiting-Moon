# audio

`music.mp3` は作品のための 5 分（300 秒）の音楽です。外部の音素材は使わず、
[`scripts/compose.mjs`](../../scripts/compose.mjs) が加算合成・ノイズ・残響で作曲・合成して書き出します。

```bash
npm run music
```

- 合図の時刻（衝突 7s、潮汐ロック 92s、着陸 200s、足跡 217.3s、タイトル 293s など）は `src/core/timeline.ts` と各シーンの定数に合わせてある。タイミングを変えたらここも直して作り直す
- 音楽が鳴っている間は、音楽の再生位置を作品の時計にして映像を同期させる
- ブラウザの自動再生制限で最初は鳴らないことがある。画面をクリックするかキーを押すと、その時点の位置から鳴り始める
- 別の音楽に差し替える場合は `music.mp3`（`music.ogg` / `music.m4a` も可）を置き換える。ファイルが無ければ無音で映像だけが進む
