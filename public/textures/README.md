# textures

NASA のパブリックドメイン画像を置いてください（無くても手続き生成で代用して動きます）。

| ファイル名 | 内容 | 入手先の例 |
|---|---|---|
| `earth_day.jpg` | Blue Marble（昼の地球、正距円筒図法 2:1） | NASA Visible Earth "Blue Marble: Next Generation" |
| `earth_night.jpg` | Black Marble（夜の都市光、正距円筒図法 2:1） | NASA Earth Observatory "Black Marble" |

- 推奨解像度は 4096×2048 以上（8K なら地球に寄ったときも綺麗）
- `.png` でも可（`earth_day.png` / `earth_night.png`）
- NASA 以外の著作物は使わないこと
